## 1. Jak se připravit na zkoušky

Zkouškové období je náročné, ale s dobrým plánem se dá zvládnout.

**Nejdůležitější pravidlo:** Začni se učit včas!

### Základní pravidla

- Plánuj si čas na učení.
- Dělej si pravidelné přestávky.
- Dostatečně spi.
- Pij vodu a nezapomínej na jídlo.
- Opakuj si naučenou látku.

*Pamatuj: I malé pokroky se počítají!*
